# Nursing Software UI Design (Paper Prototype)

## Overview
This project is a paper-based UI/UX design prototype for a nursing management software system. It was created as part of a design competition and focuses on improving usability, workflow efficiency, and user experience in a healthcare environment.

## Achievement
- 🏆 Secured 1st place in a UI/UX design competition  
- 💰 Awarded a cash prize for the design

## Objective
The goal of this design was to simplify nursing operations such as patient management, task tracking, and workflow organization through a clear and user-friendly interface.

## Design Approach
- Focused on simplicity and clarity in UI layout  
- Designed screens based on real-world hospital workflow needs  
- Prioritized ease of use for nurses and staff in fast-paced environments  

## Tools Used
- Paper prototyping  
- UI/UX design thinking  
- Hand-drawn interface planning  

## Note
This is a conceptual UI/UX project created for learning and competition purposes. It demonstrates design thinking and user-centered development approach.
